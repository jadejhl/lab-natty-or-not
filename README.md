# As IAs vão dominar o mundo atual?

## 📒 Descrição
Esse E-book de 5 páginas visa refletir a respeito do futuro das IAs no mundo atual, analisando sua evolução e avanços em diversas áreas, suas limitações e a relação humano e IA.  

## 🤖 Tecnologias Utilizadas
Utilizei o ChatGPT para definição dos tópicos e roteirização;
O Leonardo AI para criação da capa do E-book;
Ferramenta Microsoft Word para edição.

## 🧐 Processo de Criação
Utilizei o "ChatGPT" para definir os tópicos que seriam abordados no E-book sobre o mundo das IAs e então estruturar o conteúdo. Em seguida, usei o "Leonardo AI" para gerar imagens relacionadas ao tema do E-book e, concluindo, realizei a montagem final no Microsoft Word, por ser uma ferramenta para edição de texto.
